# دليل المستخدم — WebDev AI Editor

> TSK-715 (P0-6 / دفعة D-8) — دليل عربي، **Windows أولًا** (قرار D-8-ب)
> مع مسار Linux مختصر. الإصدار المرجعي: v1.0.0-rc.1.

---

## 1) ما هذه الأداة؟

محرر ويب ذكي **محلي بالكامل** يعمل على جهازك: واجهة عربية (شجرة ملفات +
محرر + محادثة AI) فوق خادم Python صغير. الذكاء الاصطناعي يقترح
التعديلات، **وأنت توافق قبل أي تنفيذ خطر** (بوابة الموافقات).

**العقد الأساسي**: الأداة مصممة لمستخدم واحد على جهاز واحد —
`http://127.0.0.1` فقط. §5 أدناه يشرح لماذا لا تتجاوز ذلك أبدًا.

## 2) المتطلبات

| المتطلب | الحد الأدنى |
|---|---|
| نظام التشغيل | Windows 10/11 (المسار الأول) · Linux (مدعوم) |
| Python | 3.10 أو أحدث — من python.org (على Windows: فعِّل "Add python.exe to PATH" أثناء التثبيت) |
| المتصفح | أي متصفح حديث (Chrome/Edge/Firefox) |
| الإنترنت | مطلوب فقط لمزودي الـ AI؛ كل ملفاتك تبقى محلية |

## 3) التثبيت والتشغيل — Windows (خطوة بخطوة)

افتح **PowerShell** أو **Windows Terminal** (يُفضَّل على cmd القديم —
انظر §6-ب) ثم:

```powershell
# 1) الدخول لمجلد الأداة (بعد فك الضغط أو الاستنساخ)
cd C:\path\to\editor

# 2) (يُنصح به) بيئة معزولة
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# 3) تثبيت مكتبات التشغيل (القائمة القانونية — requirements.txt)
pip install -r requirements.txt

# 4) التشغيل على مشروعك
python server.py --project D:\projects\my_website --port 5000
```

ثم افتح المتصفح على: **http://127.0.0.1:5000**

> لمعرفة إصدار الأداة: `python server.py --version`

### Linux (مختصر)

```bash
cd /path/to/editor
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python server.py --project ./my_project --port 5000
```

## 4) الاستخدام الأساسي

- **شجرة الملفات** (يسار): تصفح/إنشاء/حذف ملفات مشروعك.
- **المحرر** (وسط): تحرير مباشر مع حفظ آمن (كتابة ذرّية — لا ملفات ممزقة
  حتى مع انقطاع الكهرباء).
- **المحادثة** (يمين): اطلب بالعربية («أنشئ صفحة تسجيل دخول») — الـ AI
  يقترح، وأي **أمر طرفية أو تعديل خطر يطلب موافقتك أولًا**.
- **خيارات التشغيل المفيدة**:
  - `--project <مسار>` مجلد المشروع (يُنشأ إن لم يوجد)
  - `--port <رقم>` تغيير المنفذ (الافتراضي 5000)
  - `--model <مزود:موديل>` اختيار مزود AI معين
- **الإيقاف الصحيح**: `Ctrl+C` في الطرفية — سترى «إيقاف رشيق» وتُغلق كل
  المهام الحية بأمان. **لا تغلق نافذة الطرفية مباشرة** (على Windows هذا
  يعادل قتل العملية بلا تنظيف — ملفاتك سليمة لكن المهام الجارية تُقطع).

## 5) ⚠️ قاعدة الأمان الذهبية — اقرأها

الأداة **بلا مصادقة عمدًا** لأن عقدها = جهازك أنت فقط (127.0.0.1).

**لا تشغّلها أبدًا بـ `--host 0.0.0.0`** ولا تفتح منفذها في جدار الحماية
ولا تمررها عبر أي إعادة توجيه (router port-forward / ngrok / …).
من يفعل ذلك يمنح **أي شخص على الشبكة**: تنفيذ أوامر على جهازك، وقراءة
وكتابة وحذف ملفاتك — بلا كلمة سر. (التفاصيل الهندسية:
`docs/deployment_threat_model.md` §5.)

قواعد سريعة:
- ✅ `python server.py --project …` (الافتراضي 127.0.0.1) — آمن.
- ❌ `--host 0.0.0.0` — كسر للعقد، لا تفعلها.
- ❌ مشاركة الرابط مع جهاز آخر — لن يعمل أصلًا، ولا تحاول «إصلاح» ذلك
  بتغيير الـ host.

## 6) استكشاف الأخطاء (Windows)

| العرض | السبب/الحل |
|---|---|
| `'python' is not recognized` | أعد تثبيت Python مع تفعيل "Add to PATH"، أو استعمل `py` بدل `python` |
| `pip install` يفشل بشبكة الشركة | جرّب `pip install -r requirements.txt --proxy http://…` أو شبكة أخرى |
| المنفذ مشغول (`Address already in use`) | شغّل بـ `--port 8080` أو أغلق التطبيق الماسك للمنفذ |
| **(أ)** نص عربي مشوه في مخرجات أوامر cmd (`dir` مثلًا) | سلوك ترميز Windows القديم (cp1256) — الأداة لا تنهار (تستبدل الرموز)؛ الحل: `chcp 65001` قبل التشغيل أو استخدام Windows Terminal / PowerShell 7 |
| **(ب)** أغلقت النافذة والمهام اختفت | إغلاق النافذة ≠ إيقاف رشيق؛ استعمل دائمًا `Ctrl+C` (§4) |
| مضاد الفيروسات يمنع حفظ ملف | برنامج خارجي يمسك الملف — سيظهر خطأ صريح؛ أعد المحاولة بعد إغلاقه |
| الواجهة لا تفتح | تأكد أن الطرفية تعرض ترويسة «WebDev AI Editor» وأنك تفتح `127.0.0.1:5000` وليس `localhost:غيره` |

## 7) أسئلة شائعة

- **هل ملفاتي تُرفع لأي مكان؟** لا. كل شيء محلي؛ الاتصال الخارجي الوحيد
  هو طلبات مزودي الـ AI بالنص الذي تختار إرساله.
- **هل أحتاج مفاتيح API مدفوعة؟** الأداة مبنية على مزودين مجانيين؛
  اختيار المزود عبر `--model` أو من الواجهة.
- **أين تُحفظ الجلسات والنسخ الاحتياطية؟** داخل مجلد الأداة
  (`sessions/`) ونسخ الملفات الاحتياطية بجوار مشروعك — كلها ملك يدك.
- **كيف أحدّث الأداة؟** انسخ/اسحب النسخة الأحدث ثم
  `pip install -r requirements.txt` مجددًا؛ رقم الإصدار في
  `python server.py --version`.
