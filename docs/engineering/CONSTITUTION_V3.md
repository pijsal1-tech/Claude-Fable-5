1. **الدليل فوق الذاكرة**: إذا تعارضت الذاكرة/التكليف مع محتوى `docs/engineering/` الفعلي، الدليل يفوز. (أنقذ هذا المبدأ V3 نفسها من وثيقة شبح — W-13)
2. **UNKNOWN فوق الاختراع، دائمًا**: ما لا يمكن التحقق منه يُكتب `UNKNOWN` + خطة تحقق.
3. **append-only مقدَّس**: لا يُحذف تاريخ؛ التجاوز بوسم `[SUPERSEDED]` + إحالة أمامية. (P-15)
4. **لا push/branch/tag/PR أبدًا** إلا بأمر مالك صريح. القيود المحلية مسموحة ومطلوبة مبكرًا.
5. **الشجرة تُعامل كمنشورة دائمًا**: كاتب بيئي غير محكوم (Auto-Uploader) قد ينشر أي عمل محلي — فلا سرّ في الشجرة أبدًا. (W-11، دليل حي: `44c7db2`)
6. **لا اعتماد (token/secret) يُكتب في أي ملف/سجل/إخراج/قيد** — انظر §3.
7. **الأرقام فوق الصفات؛ الاستشهاد الجديد مؤرَّخ**: `file:line @ <commit|date>`. (W-6)
8. **استئناف لا إعادة تشغيل**: العمل المقفل مقفل؛ نقطة الاستئناف الوحيدة `PROGRESS.md`.

# 3. البيئة والاعتماد (جديد — يحلّ W-3/W-4/W-11)

## 3.1 بروتوكول تعافي البيئة (إلزامي عند كل فقدان sandbox)
```
1) استنساخ بالاعتماد المتاح (إخراج الأمر يُرشَّح كي لا يُطبع التوكن)
2) فورًا: git remote set-url origin <URL بلا اعتماد>
3) هوية: git config user.name/user.email
4) تحقق: HEAD المتوقع + جذر الشجرة + ملفات docs/engineering/
5) تدقيق ما-بعد-الاستنساخ (§3.3)
```
## 3.2 بروتوكول الاعتماد الملصق
- يُستعمل **للاستنساخ فقط**؛ لا يُقتبس، لا يُطبع، لا يُكتب في أي ملف/قيد/سجل.
- كل اعتماد ملصق يُعتبر **مكشوفًا**: يُذكَّر المالك في **نهاية كل جلسة** بحذفه/تدويره.
## 3.3 تدقيق ما-بعد-الاستنساخ (ضد الكاتب غير المحكوم)
- `git log` بحثًا عن قيود غير معروفة المصدر + فحص ملفات/مجلدات دخيلة في الجذر.
- كل شذوذ يُسجَّل في سجل الجلسة قبل أي عمل.
## 3.4 قاعدة القيد المبكر
- كل مخرَج مرحلي يُقيَّد محليًا فور اكتماله — القيد المحلي هو نقطة الحفظ الوحيدة المضمونة في بيئة تُمسح كل دور.
