> قرار المالك D-8-ب: **Windows أولًا مبدئيًا مع إضافة Linux مستقبلًا**.
> هذا تدقيق **ساكن** (بيئة الفحص الحالية Linux) على HEAD بتاريخ 2026-07-30.
> الخلاصة: **لا مانع بنيوي معروف للتشغيل على Windows** — الكود مكتوب
> بأنماط عابرة للمنصات أصلًا، مع نقطتي تدهور موثقتين أدناه.
> التحقق النهائي = تشغيل قائمة الفحص (§6) على جهاز Windows حقيقي بيد المالك.

## 1) الإشارات والإيقاف الرشيق (TSK-705)

| البند | الحكم | الدليل |
|---|---|---|
| `signal.signal(SIGTERM, …)` | قانوني على Windows (لا يرمي) لكنه **لا يُطلق عمليًا** — Windows لا يرسل SIGTERM | server.py:2182 |
| `SIGINT` عبر Ctrl+C في الطرفية | **يعمل** — مسار الإيقاف الرشيق كاملًا (إلغاء تعاوني + انتظار ≤5ث) | server.py:2183 + 2167-2180 |
| إشارة ثانية = خروج فوري | يعمل (Ctrl+C ثانية) | server.py:2168-2169 |

**التدهور الموثق #1**: إغلاق نافذة الطرفية أو إنهاء العملية من Task Manager
على Windows لا يمر بمسار الإيقاف الرشيق (يعادل SIGKILL). الحماية القائمة
كافية: كل الكتابات ذرّية (§3) فلا ملفات ممزقة؛ أسوأ الأثر = runs حية
لا تُلغى تعاونيًا. **لا إصلاح مطلوب** — يُوثَّق في دليل المستخدم
(«أوقف الخادم بـ Ctrl+C وليس بإغلاق النافذة»).

## 3) الكتابة الذرّية والملفات المفتوحة

النمط الموحد في كامل الكود: `tmp بجوار الملف → fsync → os.replace` —
و`os.replace` **ذرّي على Windows منذ Python 3.3** (خلافًا لـ os.rename
القديم). المواقع: core/checkpoint.py:285/:404/:556 ·
core/project_memory.py:367 · actions/file_manager.py:109 ·
actions/session_manager.py:165.

خطر Windows الكلاسيكي (استبدال ملف ممسوك بمقبض مفتوح يفشل بـ
PermissionError) **منخفض هنا**: مسح شامل لم يجد أي مقبض طويل العمر —
كل الفتحات `with open(…)` قصيرة النطاق (grep: صفر `self._fh`/مقابض
محفوظة في project_memory/checkpoint). الاستثناء الخارجي الوحيد:
برامج المستخدم (محرر آخر/مضاد فيروسات) تمسك ملفات المشروع —
سلوك متوقع يظهر خطأً صريحًا لا صامتًا.

## 4) subprocess والترميز (أخطر محور على Windows عربي)

| البند | الحكم | الدليل |
|---|---|---|
| `shlex.split(command, posix=(os.name != "nt"))` | ✅ فرع Windows موجود أصلًا | actions/command_runner.py:82 + :226 |
| built-ins الخاصة بـ cmd (`dir`, `copy`, `del`…) تُغلَّف بـ `cmd.exe /c` | ✅ موجود أصلًا | actions/command_runner.py:140-141 |
| ترميز المخرجات `encoding="utf-8", errors="replace"` | ✅ لا انهيار أبدًا | actions/command_runner.py:153-154 |
| colorama للتلوين على طرفية Windows | ✅ اختياري محروس | actions/command_runner.py:18-20 |

**التدهور الموثق #2**: مخرجات أوامر cmd القديمة على Windows عربي تصدر
بترميز **cp1256/OEM-720** لا UTF-8 — مع `errors="replace"` لن يحدث
انهيار، لكن النص العربي في مخرجات `dir` مثلًا قد يظهر مشوهًا ().
حل المستخدم الموصى به (يدخل دليل المستخدم): تفعيل UTF-8 في الطرفية
(`chcp 65001`) أو استخدام PowerShell 7 / Windows Terminal.
**لا إصلاح كود** — أي كشف ترميز تخميني أخطر من التشويه المقروء.

## 5) flask-sock والخادم

- flask-sock يعتمد `simple-websocket` (Python خالص — يعمل على Windows بلا تجميع).
- التبعيات الصلبة الأربع (flask/flask-sock/requests/pyyaml — requirements.txt)
  كلها wheels خالصة: **لا حاجة لأدوات بناء C على Windows**.
- الاختيارية الوحيدة ذات الامتداد المُجمَّع: tree-sitter — لها wheels رسمية
  لـ Windows x64، وغيابها تدهور رشيق موثق (فهرس رموز فارغ).
- `app.run(host, port)` (server.py:2185): خادم Werkzeug التطويري يعمل على
  Windows بلا فروق — وعقد المنتج localhost أحادي المستخدم يجعله كافيًا
  (RELEASE_READINESS_REPORT §5).

## 6) قائمة فحص المالك على جهاز Windows حقيقي (مطلوبة لرفع rc)

> تُنفَّذ مرة واحدة على Windows 10/11 + Python 3.10+ — النتائج تُبلَّغ
> للجلسة القادمة لتوثيقها هنا وتحويل الحالة من AUDITED-STATIC إلى VERIFIED.

1. [ ] `python --version` (≥3.10) ثم `pip install -r requirements.txt` — ينجح بلا مُجمِّع
2. [ ] `python server.py --project .\examples --port 5000` — يقلع ويطبع الترويسة
3. [ ] فتح `http://127.0.0.1:5000` — الواجهة تعمل (شجرة/محرر/محادثة)
4. [ ] إنشاء/تعديل/حفظ ملف من الواجهة — يُكتب على القرص سليمًا
5. [ ] تشغيل أمر من لوحة الأوامر (`dir`) — مخرجات تظهر (تشوه عربي مقبول — التدهور #2)
6. [ ] `Ctrl+C` في الطرفية — رسالة «إيقاف رشيق» تظهر والخروج نظيف
7. [ ] (اختياري) `pip install -r requirements-dev.txt` ثم `python -m pytest` — النسبة الخضراء تُبلَّغ كما هي
8. [ ] (اختياري) مسار مشروع بعمق عربي `D:\مشاريع\تجربة` — فتح وحفظ يعملان
