# قائمة فحص المالك — وضع سطح المكتب على Windows (D-8-ب / TSK-727c)

> املأ كل بند بـ ✅ / ❌ + ملاحظة عند الفشل. التحقق التشغيلي النهائي
> على Windows بيدك حصريًا (بيئة التطوير Linux بلا GUI — ADR-006).
> عند الانتهاء: أعد الملف مؤشَّرًا (أو الصق النتائج في رسالة) —
> إقفال P2 النهائي معلَّق على هذا التأشير.

## أ) الإقلاع والنافذة
- [ ] `python desktop.py` يفتح نافذة «WebDev AI Editor» (قبل التغليف)
- [ ] `WebDevAIEditor.exe` (بعد `pyinstaller desktop.spec`) يفتح النافذة نفسها
- [ ] لا نافذة كونسول سوداء تظهر مع الـ exe (console=False)
- [ ] إغلاق النافذة (X) يُنهي العملية كليًا (تحقق في Task Manager:
      لا python/WebDevAIEditor متبقٍ)
- [ ] تشغيل نسختين متتاليتين يعمل (منفذ حر جديد لكل نسخة — لا تعارض)

## ب) العربية وRTL
- [ ] الواجهة تظهر بالعربية واتجاه RTL سليم (الشريط الجانبي، الأزرار)
- [ ] كتابة رسالة عربية في الدردشة تُعرض بمحاذاة واتجاه صحيحين
- [ ] كتابة كود لاتيني داخل رد عربي يُعرض LTR داخل كتلة الكود

## ج) الثيمات
- [ ] مبدّل الثيمات يعمل (dark / light / monokai / high-contrast)
- [ ] الثيم المختار يبقى بعد إغلاق التطبيق وإعادة فتحه (localStorage)

## د) WebSocket والبث
- [ ] مؤشر الاتصال (النقطة) أخضر بعد الإقلاع
- [ ] إرسال رسالة دردشة يبث الرد تدريجيًا (streaming) بلا تجمّد
- [ ] زر الإيقاف أثناء البث يوقف التوليد ويعيد الواجهة سليمة

## هـ) الملفات والمحرر
- [ ] «فتح مجلد» يعمل ويعرض شجرة الملفات
- [ ] فتح ملف، تعديله، حفظه (Ctrl+S) — والتعديل يظهر على القرص
- [ ] إنشاء ملف جديد ومجلد جديد يعملان

## و) الطرفية
- [ ] فتح الطرفية وتشغيل أمر بسيط (`dir`) يعرض الخرج
- [ ] تشغيل ملف Python من زر «تشغيل» يعمل ويعرض exit code

## ز) الحواف
- [ ] `--project C:\some\path` يفتح المشروع المحدد
- [ ] بلا pywebview (بيئة نظيفة): `python desktop.py` يطبع الرسالة
      الإرشادية (pip install pywebview / python server.py) ويخرج بلطف
