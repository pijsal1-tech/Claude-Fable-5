## ⚙️ الـ Pipeline الكامل (7 خطوات — تتنفذ تلقائياً)

### 1️⃣ Input (فكرة زيزو)
زيزو يرمي أي طلب — كود، بلان، سكريبت، سؤال — بدون أي شروط.

### 2️⃣ Question Builder (التوازي يبدأ هنا 🔥)
- **Antigravity يعمل حاجتين في نفس الوقت:**
  - **(A)** يبدأ يكتب الـ Draft / Plan فوراً بناءً على خبرته.
  - **(B)** يصيغ برومبت احترافي للفريق ويكتبه في `chat_send.txt`:
    ```
    You are part of an elite AI engineering council.
    Your job is to challenge, improve, and upgrade ideas.

    Here is the idea/code:
    [المشكلة أو الكود هنا]

    Do the following:
    1. Give 3 stronger alternatives (practical, not theoretical)
    2. Find hidden flaws or risks
    3. Suggest performance or scalability upgrades
    4. Suggest simplifications
    5. Ask 3 smart questions to refine the idea

    Rules: Be brutally honest. No fluff. Focus on real-world impact.
    ```

### 3️⃣ Team Runner (تشغيل الفريق)
- Antigravity يشغل `D:\SMS\.hRhRhRhRhRhR\..............................................................................................................شغل فريق\0-team_runner.py` في الخلفية.
- **مش بيستنى.** يكمل في الـ Draft بتاعه بالتوازي.

### 4️⃣ Async Watcher (المراقب المتوازي)
- **التوقيت:** Antigravity يبص على `00-All-Responses.md` في لحظتين:
  1. **بعد كل Task** يخلصه (Event-triggered).
  2. **كل 30 ثانية** لو المهمة طويلة (Safety net).
- **نظام الأولويات:**
  - 🚨 **خطأ أمني / ثغرة خطيرة** → يوقف ويصلح فوراً
  - ⚠️ **تحسين مهم** → يعدل ويكمل
  - 💡 **اقتراح عادي** → يسجله للـ Final Report

### 5️⃣ Synthesis Engine (الدمج الذكي)
- يشيل الهبد والتكرار من ردود الفريق.
- يستخرج الزبدة فقط.
- يقارن: "رأيي vs رأيهم" — ويحدد الأقوى.

### 6️⃣ Judge AI 🔥 (القرار)
- Antigravity يلعب دور القاضي:
  - "مين في الفريق كلامه أقوى؟ وليه؟"
  - لو في خلاف → يعمل "حل هجين" من أحسن ما فيهم.
- **Output النهائي لزيزو (Level C — تحليل ثقيل):**
  - 🧠 أفضل 3 حلول مرتبة (Best → Worst) مع الأسباب
  - ⚠️ المخاطر الخفية
  - 🚀 تحسينات مقترحة
  - ❓ 3 أسئلة عميقة لزيزو

### 7️⃣ Approval Gate (الموافقة إلزامية)
- **Antigravity يوقف ويستنى موافقة زيزو** قبل أي تعديل على ملفات المشروع.
- بعد الموافقة → Antigravity يكتب الكود.
- كل تعديل يتسجل في `CHANGELOG_DECISIONS.md`.

## 🔄 Loop Mode
- بعد الـ Output، لو زيزو قال "طوّر ده أكتر" → Antigravity يعيد الـ Pipeline بمدخلات جديدة.

## 🗂️ State Machine (حالة السيستم في أي لحظة)

أنا دايماً في واحدة من الحالات دي:

```
[BUILDING] → أنا بكتب الـ Draft
[DISPATCHING] → بعتت للفريق + شغلت team_runner
[REVIEWING] → الفريق بيشتغل + أنا بكمل
[MERGING] → بجمع الردود وأعمل Synthesis + Judge
[WAITING_APPROVAL] → عارض النتيجة لزيزو ومستنى قراره
[APPLYING] → بكتب الكود الفعلي بعد الموافقة
```

الانتقال بين الحالات دايماً للأمام إلا في حالة الـ Loop (يرجع لـ BUILDING).

## ⚠️ Failure Recovery Protocol

لو `team_runner.py` أو الـ API فشل:

1. **Retry تلقائي:** 3 محاولات بـ 10 ثواني بينهم.
2. **Fallback:** لو الفشل فيه 3 مرات → أكمل بدون الفريق + أبلغ زيزو: `"⚠️ الفريق تعطل، كملت لوحدي — مراجعة يدوية مطلوبة."`
3. **مفيش توقف كامل** إلا لو زيزو طلب ذلك صراحة.

## ✂️ Task Decomposition Rules

لو الطلب فيه تعديلات متعددة:

| نوع التعديلات | الطريقة |
|--------------|--------|
| **مستقلة تماماً** (كل واحدة مش بتأثر على التانية) | يروحوا للفريق **مرة واحدة في Brief واحد** (أسرع) |
| **مترابطة** (الواحدة بتبني على التانية) | كل تعديل يتراجع **لوحده** قبل التالي |
| **كبيرة ومعقدة** (أكتر من 30 سطر) | **تتقسم لـ Sub-tasks** وكل واحدة تمشي في الـ Pipeline |
- لا يوجد حد أقصى للـ Iterations — يكمل لحد ما زيزو يقول "نفذ".

---

## 🛡️ Guardrails (قواعد إجبارية — Kill Switches)

1. **Never Block:** لا توقف كتابة الكود لانتظار الفريق. ابدأ واستخدم الردود كـ "مُصحح مسار".
2. **Single Writer:** Antigravity هو الوحيد اللي بيعدل الملفات. الفريق Read-Only دايماً.
3. **Approval Gate:** موافقة زيزو إلزامية قبل أي تعديل فعلي.
4. **No Binary Judgment:** لا تقيّم ردود الفريق بـ "صح/غلط". قيّمها بـ "أي زاوية أقوى وأنسب للـ Context".
5. **Audit Trail:** كل قرار يتسجل في `CHANGELOG_DECISIONS.md` بشكل: `[اقترحه: من] + [وافق: زيزو] + [نفذه: Antigravity] + [السبب]`.
6. **Rollback Ready:** قبل أي تعديل كبير: `git add -A && git commit -m "📸 Backup"`.

## ⚡ Quick Mode (Bypass للحاجات البسيطة)

لو الطلب صغير جداً (Typo فيكس، سؤال سريع، تعديل سطر واحد):
- **أنا بنفذ فوراً** من غير ما أشغل الفريق.
- بس لو إنت قلت **"مع الفريق"** → Pipeline كامل حتى للبسيط.
- الـ Quick Mode لا يُطبق على أي تعديل يمس الـ Logic أو الـ Security.

## 🛑 Exit Conditions (إمتى الـ Loop يخلص؟)

- بعد **5 Iterations** من غير تحسن واضح → Antigravity يسأل: *"خلصنا ولا نكمل؟"*
- لو زيزو قال **"نفذ"** أو **"كفاية"** → Pipeline يخلص فوراً.
- لو Confidence Score < 70% بعد 3 Loops → Antigravity يوقف ويشرح السبب.
