# 🔪 بروتوكول تقسيم الوظايف — Vibe Coding Micro-Tasking

> **تُفعَّل تلقائياً بـ `/تقسيم-وظايف` أو لما المهمة معقدة**
> الهدف: تقسيم أي طلب برمجي لخطوات صغيرة قابلة للاختبار الفوري

---

## ⚡ القاعدة الذهبية

```
أي طلب → قسّمه → نفّذ خطوة واحدة → اختبر → انتظر موافقة → كمّل
```

---

## 📋 خطوات البروتوكول

### [Step 1/4] — فهم المطلوب

```
اقرأ الطلب وحدّد:
  ما هو الهدف النهائي؟
  ما الملفات المتأثرة؟
  ما الـ Functions المتأثرة؟
  ما خطر الكسر (Regression Risk)؟
```

### [Step 2/4] — التقسيم (Chunking)

قسّم المهمة لـ Micro-Tasks مستقلة:

```markdown
## 📦 تقسيم المهمة

| # | Task | الملف | الدالة | قابل للاختبار؟ |
|---|------|-------|--------|--------------|
| T1 | [وصف] | [ملف] | [دالة] | ✅ نعم |
| T2 | [وصف] | [ملف] | [دالة] | ✅ نعم |
| T3 | [وصف] | [ملف] | [دالة] | ✅ نعم |

التبعيات: T2 يحتاج T1 | T3 مستقل
```

### [Step 3/4] — التنفيذ والاختبار (Execute & Test)

لكل Task:
```
1. نفّذ التعديل (جراحي — الدالة المطلوبة فقط)
2. شغّل اختبار فوري:
   - python -m py_compile file.py       ← Syntax
   - python -c "..." test logic         ← Logic
3. اعرض النتيجة
4. انتظر موافقة قبل T التالي
```

### [Step 4/4] — الموافقة والاستمرار (Checkpoint)

```
✅ PASS → أبلّغ المستخدم + انتظر "كمّل" أو موافقة
❌ FAIL → أوقف فوراً + اشرح السبب + اقترح الحل
```

---

## 🚨 قواعد لا تُكسر

```
❌ ممنوع: كتابة كود Task-2 قبل نجاح Task-1
❌ ممنوع: تعديل ملف كامل (Surgical Edits فقط)
❌ ممنوع: التسليم بدون نقد ذاتي في الآخر
✅ إلزامي: اختبار حقيقي (مش تخمين) بعد كل Task
✅ إلزامي: Checkpoint بعد كل Task
```

---

## 📐 Template الـ Task

```markdown
## Task [رقم]/[إجمالي]: [وصف]

**الملف:** `file.py`
**الدالة:** `function_name()`
**التغيير:** [سطر من → سطر إلى]
**سبب التغيير:** [ليه؟]

### الاختبار:
\`\`\`bash
python -c "test logic here"
\`\`\`

### النتيجة:
[PASS ✅ / FAIL ❌]

### Regression Risk:
[هل يكسر حاجة تانية؟]
```

## 🎯 أمثلة على التقسيم الصح

### مثال: "خلّي الموديلين يشتغلوا بالتوازي"

```
❌ غلط: اكتب الكود كله دفعة واحدة

✅ صح:
  T1: استورد threading في أول الملف → اختبر Syntax
  T2: حوّل get_ai_response في thread → اختبر Logic
  T3: اجمع النتايج بعد join → اختبر End-to-End
```

## ⚡ اختصارات التواصل

| الكلمة | المعنى |
|--------|--------|
| `كمّل` | الـ Task نجح، روح للتالي |
| `وقّف` | في مشكلة، اشرح |
| `اختبر` | شغّل الاختبار الحالي |
| `راجع` | ارجع للـ Task السابق |
