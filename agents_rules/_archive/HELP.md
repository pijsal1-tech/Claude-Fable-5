## ⚡ أوامر سريعة — انسخ وابعت

| قولها | إيه بيحصل |
|-------|----------|
| `ابدأ` | يقرأ الملفات → يكتب خطة → يستنى موافقتك |
| `بلان` | يكتب plan.md بس — مش ينفذ |
| `كمل` | ينفذ الخطوة التالية |
| `راجع` | يقرأ ويحلل — مش يعدل |
| `وقف` | يوقف كل حاجة فوراً |
| `فكّرني` | يقرأ AGENTS.md + plan.md ويقولك وصلنا فين |
| `شغّل الفريق` | يكتب brief → يشغّل team_runner |
| `فين الـ Status Bar؟` | يعرض جدول الحالة فوراً |

## 🚨 مشاكل شائعة — الرد الجاهز

### 🟡 نسيان وأخطاء بسيطة

| المشكلة | انسخ وابعت |
|---------|-----------|
| نسى الـ Status Bar | `"فين الـ Status Bar؟ حدّثه فوراً"` |
| نسى الخطة | `"اقرأ plan.md — نفذ بس اللي فيه"` |
| بيكتب كود من دماغه بدون plan.md | `"وقف — اكتب خطة في plan.md أولاً وانتظر موافقتي"` |
| context ضاع أو بينسى | `"فكّرني — اقرأ AGENTS.md + plan.md"` |
| بيشرح أكتر من اللازم | `"مش محتاج شرح — نفذ بس"` |

### 🔴 أخطاء خطيرة

| المشكلة | انسخ وابعت |
|---------|-----------|
| عدّل ملف مش في الخطة | `"Fatal: ارجع التعديل فوراً — ازاي عدلت من بره الخطة؟"` |
| حذف كود | `"ممنوع حذف — ارجع الكود اللي مسحته"` |
| كتب TODO في الكود | `"ممنوع TODO — اكتب الكود كامل أو متكتبوش"` |
| غيّر interface أو API | `"ممنوع — ارجع وشرح المشكلة نظرياً بس"` |
| كسر حاجة شغالة | `"تراجع — شغّل الكود القديم وتأكد شغال أولاً"` |
| بيهلوس أو كلام مش منطقي | `"وقف — اقرأ AGENTS.md تاني وابدأ من الأول"` |

### 🛠️ مشاكل تقنية

| المشكلة | الحل |
|---------|------|
| plan.html مش بتفتح | شغّل يدوي: `python plan_viewer.py` |
| الفريق مش خلص | شغّل: `python check_done.py` |
| عايز توقف الفريق | شغّل: `python kill_team.py` |
| الملف فيه syntax error | قوله: `"اختبر بـ py_compile أولاً"` |

## 💬 جمل مفيدة لكل مواقف

```

```
