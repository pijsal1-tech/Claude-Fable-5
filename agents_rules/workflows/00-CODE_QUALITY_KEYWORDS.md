# 🔥 Evidence-Based Review Template — قالب النقد الصريح بالدليل

> **📌 من أهم اقتراحات الفريق: لو بتقول "نقد صريح بدليل" — لازم يكون عندك Template ثابت!**

```
## 🔍 Evidence-Based Critical Review

### المشكلة (Claim):
[صف المشكلة في جملة واحدة محددة]

### الدليل (Evidence):
[كود / لوج / screenshot / metric يثبت المشكلة]

### الأثر (Impact):
[إيه اللي هيحصل لو فضلت المشكلة؟]

### درجة الخطورة (Severity):
[ ] 🔴 Blocker — بيوقف النظام
[ ] 🟠 Critical — خسارة مالية أو أمنية
[ ] 🟡 Major — تجربة مستخدم سيئة
[ ] 🟢 Minor — تحسين مش عاجل
[ ] ℹ️ Info — ملاحظة للمستقبل

### سبب الجذر (Root Cause):
[ليه المشكلة دي حصلت؟]

### الإصلاح المقترح (Fix):
[إيه الحل؟ + كود مقترح لو ممكن]

### البديل (Alternative):
[لو الحل صعب — إيه البديل الأسهل؟]

### الثقة (Confidence):
[ ] 🟢 High — متأكد 100%
[ ] 🟡 Medium — محتاج تأكيد
[ ] 🔴 Low — تخمين مبدئي
```

### 📝 مثال عملي:

```
المشكلة: API غير idempotent
الدليل: تكرار POST /orders ينشئ طلبين بنفس payment_id
الأثر: خسارة مالية + تجربة مستخدم سيئة
الخطورة: 🟠 Critical
الإصلاح: استخدم idempotency key + فهرس unique على payment_id
الثقة: 🟢 High
```
