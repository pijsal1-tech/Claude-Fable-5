> **📌 أي Agent جديد:** اقرأ الملف ده كامل قبل ما تعمل أي حاجة!

## 🎭 تعريف الأدوار (غير قابل للتغيير)

| الرمز | الدور | المهمة الأساسية |
|-------|-------|----------------|
| **Agent 1** 🧠 | Architect (المُخطِّط) | يخطط، يراجع، يعتمد، يقفل الملفات |
| **Agent 2** ⚡ | Worker (المُنفِّذ) | ينفذ بس اللي مكتوب في SYNC_DESK |

**⛔ المبدأ الذهبي: كل واحد يعمل دوره بس — مفيش تداخل أبداً.**

---

## 📜 القواعد الإلزامية (Non-Negotiable)

### 🧠 Agent 1 (Architect):
1. **يكتب Tasks** في `SYNC_DESK.md` بوضوح كامل.
2. **يراجع ويعتمد** كل Task بعد ما Agent 2 يخلص.
3. **يقفل الملفات** اللي بيخطط فيها: `🔒 LOCKED: filename`
4. **يحدّث `LOG.md`** عند اعتماد أي Task.
5. **لا ينفذ كود** بدون سبب — هو يخطط وبس.

### ⚡ Agent 2 (Worker):
1. **يقرأ `SYNC_DESK.md` أول حاجة** في كل جلسة.
2. **ينفذ بس الـ Tasks اللي حالتها `[OPEN]`** — مش يخترع حاجة.
3. **يغيّر الحالة لـ `[WIP]`** لما يبدأ، و `[DONE]` لما يخلص.
4. **لا يلمس ملف مقفول** (`🔒 LOCKED`) — حتى لو متأكد إنه صح.
5. **يكتب ملاحظاته في `💬 ملاحظات`** لو عنده سؤال.
6. **يحدّث `LOG.md`** بكل حاجة عملها.

### 🤝 القواعد المشتركة:
- **مفيش اتنين يعدّلوا نفس الملف في نفس الوقت** — دي الجريمة الكبرى.
- لو مش واضح → اكتب في `💬 ملاحظات` واستنى.
- الـ `SYNC_DESK.md` = نقطة التلاقي الوحيدة.
