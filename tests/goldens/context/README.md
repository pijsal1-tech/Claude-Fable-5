# Legacy Context Goldens — T-017 (R-201)

شبكة أمان الـ parity قبل استخراج كتلة جمع السياق المضمّنة في `server.py`
(معالج `message`: استخراج الـ mentions → بحث `rglob` → حقن محتوى الملفات →
`fm.get_project_context()`) إلى `ContextEngine` في R-201.

كل golden = لقطة JSON لما "يراه الموديل" بالضبط لرسالة تمثيلية ضد
`tests/fixtures/sample_project/`. أي انحراف في المخرجات يفشل الاختبار
بصوت عالٍ — والـ engine الجديد يجب أن يبقى أخضر ضد نفس الملفات.

## السيناريوهات الستة

| Golden | الرسالة | ما يثبته |
|---|---|---|
| `mention_only` | «اقرأ config.json وقولي ايه المشكلة» | مسار الـ **exact-match**: اسم ملف بامتداده → ملف واحد مُضمَّن بمحتواه المرقّم. |
| `keyword_only` | «فيه مشكلة في database» | مسار الـ **stem-match** المرن: كلمة بلا امتداد → `rglob(*database*)` يلتقط `src/database.py`. |
| `mixed` | «قارن بين src/app.js و auth بالتفصيل» | المساران معًا: مسار فرعي صريح + كلمة مفتاحية → ملفان بالترتيب (exact ثم stem). |
| `no_context` | «اشرح لي مفهوم الـ closures في جافاسكريبت» | **لا مطابقة**: قائمة فارغة والنص يمر كما هو حرفيًا (لا حقن، لا عنوان). |
| `huge_file` | «افتح big_data.js وشوف المشكلة» | **quirk مثبَّت**: ملف >`MAX_FILE_SIZE` (500KB، يُنشأ في `setup`) يُذكر في القائمة والعنوان يدّعي «تم قراءة 1 ملف» لكن `read_file` يفشل بصمت — **بلا أي كتلة محتوى**. |
| `arabic_filename` | «حدث وحدة_المصادقة.py وأضف تحقق» | `\w` في الـ regex يلتقط العربية: `src/وحدة_المصادقة.py` (يُنشأ في `setup`) يُطابَق ويُضمَّن. |

## بنية اللقطة

```json
{
  "scenario": "...", "description": "...",
  "message": "نص المستخدم الخام",
  "mentioned_files": ["مسارات نسبية بالترتيب"],
  "user_text_with_files": "النص بعد الحقن (المسارات المطلقة → <ROOT>)",
  "project_context": "مخرجات fm.get_project_context() (<ROOT> مطبَّع)"
}
```

## الملفات

- `harness.py` — نقل **حرفي** لكتلة server.py مع إصلاحَي حتمية للترتيب فقط
  (فرز نتائج `rglob` وفرز الـ sets قبل التكرار — ترتيب legacy الفعلي غير
  حتمي أصلًا؛ *مجموعة* الملفات المضمّنة هي نفسها). كل الـ quirks الأخرى
  محفوظة عمدًا، بما فيها الثابت الكاذب `MAX_MENTIONED = 100  # حد أقصى 10 ملفات`
  وعدم فلترة الملفات السرية/الحجم في مرحلة الـ mention.
- `capture_goldens.py` — إعادة التوليد:
  `python3 -m tests.goldens.context.capture_goldens`
  ⚠️ لا تعِد التوليد إلا عند تغيير **مقصود** في سلوك legacy نفسه —
  R-201 استخراج حافظ للسلوك ويجب ألا يحتاجها.
- `test_replay_goldens.py` — 6 اختبارات parity مُعاملة + 4 اختبارات
  تثبيت quirks (huge-file بلا محتوى، no-context بلا تعديل، لا مسارات
  أجهزة في الـ goldens، السيناريوهات الستة بالضبط).
