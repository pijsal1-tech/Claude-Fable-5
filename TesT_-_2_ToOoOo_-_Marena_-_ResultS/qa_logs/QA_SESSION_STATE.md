# QA Session State — اختبارات فقط

## قاعدة الجلسة
- الهدف: اختبارات فقط لا غير.
- ممنوع إصلاح كود الإنتاج أثناء هذه المرحلة.
- ممنوع إضافة Features.
- المطلوب: تسجيل نتائج الاختبارات، المشاكل، واقتراحات إصلاح فقط كمرجع للمهندس.

## طريقة العمل
1. المساعد يعطي اختبار واحد واضح.
2. المستخدم يجرب الاختبار في التطبيق/الواجهة.
3. المستخدم يرسل النتيجة الفعلية كما حدثت.
4. المساعد يصنف النتيجة: PASS / BUG / NEEDS REVIEW.
5. إذا كانت مشكلة، تُضاف أو تُحدّث في ملف البند المناسب.
6. إذا تكررت نفس المشكلة، لا نفتح ملف جديد؛ نضيف حالة إعادة إنتاج داخل نفس ملف المشكلة.
